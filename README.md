# nodeseek-monitor

hostloc / nodeseek 关键词监听 · 关键词管理面板

- 线上地址: https://apps.998365.xyz/apps/nodeseek-de28967c-effa-11ef-b55d-325096b39f47/
- 功能: 空格分隔多词组，关键词不分顺序，同时监听 hostloc 和 nodeseek
- 存储: `nodeseek.txt` 明文，每行一条规则
- 接口: `add.php` / `delete.php` / `index.php`

## 文件
- `index.php` — 管理面板 UI
- `add.php` — 添加规则
- `delete.php` — 删除规则
- `nodeseek.txt` — 规则列表
